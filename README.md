# Lumina

Lumina is an install page for iPad.

Open it in Safari. Install the profile once. After that, tap **Install** on any app listed on the site.

## Install

1. Open Lumina in **Safari**. Other browsers will not show the install prompt.
2. Tap **Download Profile**.
3. Go to **Settings → General → VPN & Device Management**.
4. Install the Lumina profile. This only adds a home-screen shortcut to the site.
5. Return to Lumina and tap **Install** on an app.
6. Confirm the system install sheet.
7. If iPadOS says the developer is untrusted, go back to **VPN & Device Management** and trust that developer.

## Download instead

If **Install** does nothing, tap **Download** and save the IPA. You can then open that file in an installer you already have.

## What the profile does

The profile is a web clip. It does not grant extra system access and it does not silently install apps.

## If an app won’t open

The signing identity used for that build may have been revoked or is not trusted on this device. Remove the app, trust the developer again, or wait for a newly signed build on the site.

## Support

Use Safari on iPadOS. Keep the device online during install. If a listing is missing, the site catalog has not been updated yet.
